# Operating Systems Web Crawler

Contributors: Nneka Okigbo, Mariana Cantero, Sara Ali, and Derrick Mensah

## Build Steps
In order to build this,

```bash 
make clean
make
```

## Run Steps

To run to indexer: In Terminal A

```bash
./indexer --ipc /tmp/crawl.sock --out data/index
```

To run the crawler: In Terminal B

```bash
./crawler --seed https://example.com --max-depth 3 --max-pages 1000 -t 12 --out data --ipc
/tmp/crawl.sock
```

To run the querier: In any terminal

```bash
query --index <dir> <term1> <term2> ... <termX>
```
