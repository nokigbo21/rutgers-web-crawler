Linux (/'lɪnʊks/ drío łe lezi de l'Alfabéto Fonètico Internasionałe) el xe ła denominasion de un sistema operatio e el xe el nóme de un núcleo. El xe uno de i paradigmi de sviłupo de el software łibaro (e de el codexe verto), ndo chel codexe fonte el stà disponìbiłe públicamente e cualsevoja persona, co conosense informadeghe oportune, ła pol łibaramente studiar-lo, usar-lo, modificar-lo e redistribuir-lo.

El termine Linux el fa cao al núcleo Linux, parò el xe pi comunamente utiłisà pa descrivare el sistema operativo tipo Unix (chel inplementa el standar POSIX), chel utilixa primordialmente filosofía e metodołoje łibari. El núcleo nol xe parte ofixiałe de el projeto GNU (chel ga el so propio núcleo chel xe drio sviłuparse, ciamà Hurd), parò el xe distribuío baso términi de ła lixensa GNU GPL.

La espresion Linux ła xe anca utilixà pa referirse a łe distribusion GNU/Linux, cołesion de software che łe usa gaver rento cuantità grande de pachéti anca del núcleo. El software che łe xe sòite incluidare consta de na enorme difarensa de aplicasion, cofà: server web, server de posta, server FTP, ecetera. Sensa usar termini tecnici a se aplica el łema Linux a ste últime mensionà, anca se saría incoreto, dao che ła distribusion ła xe ła forma pi fasiłe e popołar pa otener un sistema GNU/Linux.

La marca Linux (Numero de serie: 1916230) el partien a Linus Torvalds e el se definise cofà "un sistema operatio pa pc che el fasiłita el so uso e łe so operasion".

Dal so łanso, Linux el ga incrementà ła so popołarità intel mercà de servers. La so flexibiłidà ła ga permetesto chel sipia utiłisà inte un rango ben grando, da uso personałe, a architetura, a ła organisaxion de inpresa: personal computers, supercomputers, dispositíi portatiłi, ecetera.

I sistemi GNU/Linux łi funsiona sora pi de 20 plataforme difarenti de hardware; tra ste chi łe pi comun łe xe cuełe dei sistemi compatìbiłi co PCs x86 e x86-64, computers Macintosh, PowerPC, Sparc e MIPS.

En pi a ghe xe łi Grupi de Usuari de GNU/Linux inte scuasi tute łe bande del pianeta.

Distribusion varie de Linux

[canbia | canbia el còdaxe]

Na distribusion ła xe un s-ciapo de aplicasion reuníe inte un grupo, na inpresa o persone, i feri de el mestier pa consomejare sistemi de pacheti de software utiłi.

A ghe xe un sbaro de distribusion GNU/Linux. Cada distribusion ła pol ver rento cualsevoja numaro de software adisional, co anca łi softwares che i fasa pi fasiłe ła instalasion de el sistema. La base de el software rento cada distribusion el ga el núcleo Linux, ndo che de sołito a se xonta anca altri pacheti vari de software.

I feri del mestier che a se usa metare rento łe distribusion de sto sistema operativo łe se cata da racuante fonti, cofà el GNU e el BSD. Usualmente a se utiłisa ła plataforma XFree86 o ła X.Org pa tegner suso el intermuso gráfeghi.

Aplicasion de i sistemi GNU/Linux

[canbia | canbia el còdaxe]

Co ła so adosion (Linux) de un numaro bastansa significativo de inprese, i fabricanti de PC, racuanti computers łi xe vendesti co distribusion GNU/Linux pre-instałade, e Linux el ga scumisià esar inportante in el vasto marcà de i PC.

GNU/Linux el dà na interfàcia grafega alternativa a ła tradisionałe interfàcia de linea de comandi de Unix. A ghe xe pi de un s-ciapo de interface grafeghe, che łe xe profexionałi e che łe xe drio permetare che GNU/Linux el sipia adato cofà fero del mestier de el desktop.

Na s-cianta de distribusion łe fa si che el scumixio de Linux el sipia direto da un disco conpato (ciamà LiveCD) sensa modificar in asoluto el hard disk de el PC ndo che se ga Linux. Pa sto tipo de distribusion, in jenerałe, i archivi de someja (archivi ISO) łi xe disponìbiłi in Internet pa ła so descarga.

Altre posibiłità łe xe scumixiar ła atività da na rede (ideałe pa sistemi co requisií minemi) o da un disco flexibiłe o discheto.

La majoransa de i codixi de Linux (pi de el 70%) łi xe del lenguajo C, parò łi xe sta utilixà un mucio anca altri lenguaji: C++, Bash, Lisp,Perl, Fortran e Python.

Pi o manco ła metà de el so codexe totałe (contà in linee de codixe) el xe stà łibarà baso ła łixensa GPL.

Storia

[canbia | canbia el còdaxe]

La storia de Linux ła xe stà un mucio vincołà a cueła de el projeto GNU. El projecto GNU, scumixià intel 1983, el ga cofà obietivo el sviłupo de un sistema Unix conpleto conposto tuto de software łibari. Sora el 1991, cuando ła prima version de el núcleo Linux ła xe liberà, el projeto GNU nol gavea a che fare co el núcleo chel definise un sistema operativo. Tutavia Linus Torvalds, chel jera drio studiare a ła Università de Helsinki, ga rienpío el buxo finałe chel sistema operatio GNU exijea. Daspó, meiare de programadori vołontari in volta pal mondo łi ga partexipà intel projeto, mejorandoło continuamente. Torvalds e altri de i primi vołontari de Linux i ga adatà o conponenti de GNU pa laorar co el núcleo Linux, creando un sistema operatio conpletamente funsionałe.

Cogna mensionar che parò el núcleo de Linux nol xe parte ofixiałe de el projeto GNU.
