util-linux is a package of utilities distributed by the Linux Kernel Organization for use in a Linux operating system. A fork, util-linux-ng (with ng meaning "next generation"), was created when development stalled,[4] but as of January 2011[update] has been renamed back to util-linux, and is the official version of the package.[5]
