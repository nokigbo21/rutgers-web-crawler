Linux
ຜູ້ກໍ່ຕັ້ງລີນຸສ ທໍວາວສ໌
ເວັບໄຊkernel.org
ເປີດໂຕ17 ກັນຍາ 1991; 34 ປີກ່ອນ (1991-09-17)

ລີນຸກຊ໌ (ອັງກິດ: Linux) ເປັນລະບົບປະຕິບັດການທີ່ບໍ່ເສຍຄ່າ ແລະ open-source ທີ່ຖືກພັດທະນາໂດຍ ລີນຸສ ທໍວາວສ໌ (Linus Torvalds) ໃນປີ 1991. ມັນຖືກອີງໃສ່ລະບົບ Unix ແລະເປັນລະບົບທີ່ມີຄວາມປອດໄພ, ມີຄວາມຍືດຫຍຸ່ນ ແລະນິຍົມໃຊ້ໃນເຊີບເວີ, ລະບົບຝັງຕົວ, ແລະຄອມພິວເຕີສ່ວນບຸກຄົນ.

ເຊິ່ງໃນເບື້ອງຕົ້ນໄດ້ປ່ອຍອອກມາໃຫ້ຜູ້ໃຊ້ທົ່ວໄປໃນປີ 1991. ໃນປັດຈຸບັນມັນຢູ່ພາຍໃຕ້ GNU General Public License (GPL). ເມື່ອເວລາຜ່ານໄປ, Linux ໄດ້ເຕີບໂຕຢ່າງກ້າວກະໂດດແລະກາຍເປັນຫນຶ່ງໃນໂຄງການ open-source ທີ່ໃຫຍ່ທີ່ສຸດໃນໂລກ. ມັນໄດ້ຊະນະຫົວໃຈຂອງຜູ້ຊ່ຽວຊານດ້ານໄອທີ, ຄົນຮັກຄອມພິວເຕິ, ແລະນັກອະດິເລກຈາກທົ່ວໂລກ.

ເຊັ່ນດຽວກັນກັບລະບົບປະຕິບັດການອື່ນໆເຊັ່ນ Windows ຫຼື MAC, ມັນຈັດການຊັບພະຍາກອນຂອງຮາດແວຂອງລະບົບເຊັ່ນ CPU, RAM ແລະບ່ອນເກັບຂໍ້ມູນ. kernel interfaces ລະບົບປະຕິບັດການແລະຮາດແວທີ່ຕິດພັນແລະອໍານວຍຄວາມສະດວກໃນການສື່ສານ.

Distro

[ດັດແກ້]

Distro (ຫລື Linux Distribution) ແມ່ນຊຸດລະບົບປະຕິບັດການ ທີ່ຖືກສ້າງຂື້ນໂດຍນຳເອົາ Linux Kernel ໄປລວມກັບໂປຣແກຣມ ແລະ ຄ່າຕັ້ງຄ່າຕ່າງໆ ທີ່ໃຊ້ງານໄດ້ຈິງ. ບໍ່ເຫມືອນລະບົບອື່ນໆ ເຊັ່ນ Windows ຫລື macOS ທີ່ມີເພີງພາລະບົບດຽວ, Linux ມີຊຸດແຈກຢາຍຫຼາຍຫຼາຍຕາມ

ຈຸດປະສົງແລະຄວາມຕ້ອງການຂອງຜູ້ໃຊ້.

ພວກມັນສາມາດເປັນ Desktop OS, Server OS, ລະບົບຝັງຕົວ (Embedded System) ຫລື Cybersecurity OS ໄດ້.

ປະເພດຂອງ Linux Distros

[ດັດແກ້]

ມີການແບ່ງ Linux Distros ອອກເປັນຫຼາຍໂຕກຸ່ມ ຂຶ້ນຢູ່ກັບການໃຊ້ງານ:

  • Ubuntu - ຍອດນິຍົມທີ່ສຸດ ມີຄວາມເຂົ້າໃຈງ່າຍ.
  • Linux Mint - ສະແດງຜົນໃກ້ຄຽງ Windows.
  • Debian - ສະຖຽນ, ປອດໄພ, ທົນທານ.
  • Fedora - ມີເຄຶ່ອງມືທັນສະໄໝ ໃຊ້ Red Hat Technology.
  • Arch Linux - ຍືດຫຍຸ່ນສູງ ຜູ້ໃຊ້ກຳນົດໄດ້ເອງ.
  • Zorin OS - ດີສຳລັບຄົນທີ່ຢ້າຍຈາກ Windows.
